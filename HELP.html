WindowMinimize

简体中文

WindowMinimize lives in the notification area and minimizes the foreground window with global hotkeys.

Hotkeys

ActionDefault
Minimize the foreground windowWin+Q
Move to the other screen, then minimizeWin+S
Restore the most recently minimized windowWin+W

Screen switching

Win+S minimizes the window on the source screen, then moves its restore position and taskbar button to the other configured screen. The window keeps its relative position within the work area. The minimize animation stays on the source screen; the restore animation is prepared for the target screen.

Screen A and Screen B are selected in the settings dialog. A window on A moves to B, a window on B moves to A, and a window on another screen moves to B.

Restore history

By default, Win+W restores windows minimized by this tool. Enable Record minimized windows from all programs to include windows minimized from the taskbar or other programs. The history is kept in memory; previously minimized windows are collected when the option is enabled.

Settings

The settings dialog controls the three hotkeys, the mode, the language, the screen pair, the restore animation, all-window history, update checks and startup.

The question mark in the title bar opens this document. Choose Minimize to keep a taskbar button, or Hide to remove the window from the screen and taskbar; hidden windows are restored from the tray menu.

Updates

The program checks the latest stable GitHub release at startup when enabled. Use Check for updates in the tray menu for a manual check. Automatic updates download the matching full or lite executable, verify the release SHA-256 checksum when available, replace the executable after exit, and restart the program.

Permissions

Windows does not send hotkeys to a normal process while an elevated window is in front. Start WindowMinimize as administrator, or enable the elevated startup option, to handle those windows.

Configuration is stored in hotkey.ini next to the executable, or under %APPDATA%\WindowMinimize when that directory is not writable.
